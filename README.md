# 🎬 Netflix Analytics Dashboard

An interactive **Netflix Analytics Dashboard** that provides insights into Netflix’s catalog of Movies and TV Shows using visual analytics. This project explores content distribution by **country, year, genre, rating, and type**, helping users understand trends and patterns in Netflix data.

---

## 📌 Project Overview

This dashboard analyzes Netflix data to answer questions such as:

* How is Netflix content distributed across countries?
* What is the split between Movies and TV Shows?
* Which genres are most popular?
* How has Netflix content grown over the years?
* What ratings dominate the platform?

The dashboard is designed with a **dark Netflix-themed UI** for better visual appeal and clarity.

---

## 📊 Dashboard Features

### 🔹 Key Metrics & Filters

* **Type**: Movie / TV Show
* **Title Selector**
* **Rating** (TV-MA, TV-14, PG-13, etc.)
* **Release Year & Date Added**
* **Duration**
* **Genre & Description Panel**

### 🔹 Visualizations Included

* 🌍 **Total Movies & TV Shows by Country** (World Map)
* 🎥 **Movies vs TV Shows Distribution** (Donut Chart)
* ⭐ **Ratings Distribution** (Bar Chart)
* 🎭 **Top 10 Genres** (Horizontal Bar Chart)
* 📈 **Total Movies & TV Shows by Year** (Area Chart)

## 📂 Dataset

The dataset contains information such as:

* Title
* Type (Movie / TV Show)
* Country
* Release Year
* Date Added
* Rating
* Duration
* Genre
* Description

> Dataset Source: Public Netflix dataset (commonly used for data analytics projects)

---

## 📈 Insights Derived

* Movies dominate Netflix’s catalog compared to TV Shows.
* The United States contributes the highest number of titles.
* Drama-related genres appear most frequently.
* Significant growth in content addition after 2015.
* TV-MA is the most common rating on Netflix.
